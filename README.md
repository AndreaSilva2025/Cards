📦 Projeto: Card Interativo com CSS Responsivo
Desenvolvi um projeto visualmente atrativo e funcional utilizando HTML e CSS puro, com foco em um layout limpo, moderno e intuitivo. A proposta foi criar cards interativos com botões de ação e ícone de favorito, organizados em linhas flexíveis e responsivas.

🔧 Tecnologias Utilizadas:
HTML5

CSS3 (Flexbox)

Ícones vetoriais (Flaticon)

🎯 Funcionalidades:
Layout responsivo com organização em linhas (flexbox)

Botão de ação com estilo personalizado

Ícone de "favorito" posicionado dinamicamente

Cartões com imagem, texto e botão

Estética clean e sombra para profundidade

✨ Destaques do Código:
Uso de flexbox para centralização e espaçamento automático entre os elementos

Estilização de botões com interatividade e acessibilidade

Ícone de coração flutuante com position: absolute para efeito visual moderno

💡 Aprendizado:
Esse projeto foi essencial para reforçar meus conhecimentos em layout responsivo, boas práticas de organização CSS, e a importância da atenção aos detalhes visuais para criar interfaces amigáveis e atrativas.
